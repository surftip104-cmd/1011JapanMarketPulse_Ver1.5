JapanMarketPulse 5軸スコア追加版（起動修正版）

【Windowsで起動】
1. このZIPを右クリックして「すべて展開」します。
2. 展開したフォルダー内の run_JapanMarketPulse.bat をダブルクリックします。
3. 初回起動時は必要なライブラリを自動インストールします。数分かかる場合があります。
4. 起動後、ブラウザが開いたら銘柄コードを入力します。

【GitHub → Streamlit Cloudで起動】
重要：このZIPは app.py と requirements.txt がZIP直下にあります。
1. ZIPを展開します。
2. 展開した中身（app.py、requirements.txt、各 .py ファイル、margin_cache フォルダー）をGitHubリポジトリの一番上（ルート）へアップロードします。
   フォルダーごと一段深く入れないでください。
3. Streamlit Cloudの Main file path は app.py にします。
4. Deploy/Rebootします。

【起動できない場合】
黒い画面に表示されたエラーの最後の10～20行、またはStreamlit Cloudの赤いエラー画面をスクリーンショットで送ってください。エラー内容を見て修正します。

【注意】
- 大口動向は公開された機関空売り・信用増減データを使います。リアルタイムの歩み値ではありません。
- データが取れない場合は「未取得」と表示し、推測値を入れません。
- 本アプリは売買判断の参考用です。売買推奨や利益を保証するものではありません。
